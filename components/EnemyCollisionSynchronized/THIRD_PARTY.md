# Third-party inputs

LuaJIT is a separate MIT-licensed build dependency pinned in `dependencies.json`. Its compiler and sources are not bundled. The runtime uses the game's existing LuaJIT/FFI interfaces and Windows APIs.

Helldivers 2 and its assets belong to their respective owners. This unofficial mod distributes authored source and compiled mod resources, not game executables, extracted game bytecode, native disassembly or memory captures. The archive and package helpers are adapted from the existing CowboyBingus projects.
