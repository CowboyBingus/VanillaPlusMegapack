# Third-party dependencies

The build uses [LuaJIT](https://github.com/LuaJIT/LuaJIT), licensed under MIT. Its pinned revision appears in `dependencies.json`. Compiler sources and binaries are obtained separately.

Helldivers 2 and its game assets belong to their respective owners. This is an unofficial mod project. A supported game installation is required for building; no game executable, extracted resource, native decompilation or crash dump is included in source control. The only memory capture is the snapshot replay's read-only fixture `tests/current_game_25327279.lua` (2,526 captured bytes; see [privacy scope](docs/PRIVACY.md)).

Generated artwork is documented in [assets/ARTWORK.md](assets/ARTWORK.md). This repository is licensed under the Zero-Clause BSD license (0BSD, see `LICENSE`): use, copy, modify and distribute it for any purpose, with no conditions. Upstream dependencies keep their own licenses.
