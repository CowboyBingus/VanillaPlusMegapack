Vanilla Plus Megapack Rows - v27

Supports Steam build 25327279 / EXE 1.8.45850.0.
Requires the separate Bingus Shared Loader v16 or newer / API 1.

1. Close Helldivers 2 and use either Arsenal or HD2MM.
2. Disable previous megapacks and standalone copies of features you want off.
   Enable only one Megapack variant (standard or Rows).
3. Import Vanilla-Plus-Megapack-Rows-v27.zip and Bingus Shared Loader v16 or newer.
4. With Arsenal's default priority, place the loader LAST. If first-mod
   priority is enabled, place the loader FIRST instead.
5. Open the pack's Options and select any of the thirteen independent mods.
   Review these choices after updates; defaults depend on your manager.
6. Purge / Deploy, then start the game. Close the game before changing options.

Install Mod Bindings Menu v1.0 separately to rebind Galactic Menu Hotkey under
Mouse & Keyboard > General > MODS. Without it, the hotkey uses Tab aboard
the ship while no menu is open. Controller activation is not yet supported.
Mod Bindings Menu is not bundled in either Megapack variant.
